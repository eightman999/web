■ ツール・アプリケーション

DiffLoupe
使用技術: Swift / SwiftUI

WinMerge難民のための、macOSネイティブなフォルダ差分ツール。2つのフォルダを再帰比較して「一致／相違／左右のみ」を色分け表示し、テキストは行単位で差分を出します。比較エンジンは1万ファイルを約0.66秒で処理し、約6万ファイル規模の実フォルダ比較も完走。XCTest 19件すべてパス済みです。

GitHub
Uzume
使用技術: JavaScript / Web Audio API

音符・和音・小節・ループ・楽想表現を記述できる独自の音楽プログラミング言語と、そのコンパイラ。AST・パーサー・発音までをゼロから自作し、Web Audio APIでブラウザ上で実際に鳴らせます。仕様書つき。

Uzume Playerを試す 言語仕様 GitHub

■ ライブラリ・開発支援

hoi4-modding-skills
使用技術: Markdown / Python / AIエージェント連携

HOI4のMOD制作という専門作業をAIエージェントに委任するための、再利用可能なスキル集とリファレンス。20種以上のスキルを設計・パッケージ化し、中核のスキルは実作業で延べ160回以上呼び出されている、「作って終わり」ではない実運用中の資産です。

GitHub
jinjya-api
使用技術: TypeScript

このサイトの「今日のおみくじ」を動かしている自作のWeb API。神社ごとのおみくじの登録・抽選・奉納の機能を提供します。デモで終わらせず、当サイトで実際に本番運用しているのがポイントです。

動かしてみる（おみくじ） GitHub

Ourin（桜鈴）【開発中】
使用技術: Swift / C++

「伺か」互換のデスクトップマスコット基盤を、macOSネイティブでフルスクラッチ実装中の挑戦的プロジェクト。SHIORI・SSTP・SakuraScript・SERIKOなど多数のプロトコルに取り組み、現在は379の単体テストが通る段階です。複数のAIによる相互コードレビュー体制を組んで品質を詰めています。
